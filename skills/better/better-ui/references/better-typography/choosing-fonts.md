# Choosing fonts

Font categories, fallback stacks for a type change, file formats, loading and why fonts look the way they do.

## Choosing a typeface

| Category | Traits | Use for |
| --- | --- | --- |
| Serif | Small strokes at the ends of letters guide the eye along a line | Long passages, editorial reading |
| Sans-serif | Clean, even shapes that stay crisp at small sizes | Default for most interfaces |
| Monospace | Every glyph the same width | Code and fixed-width identifiers; numeric columns use `tabular-nums` instead |
| Display | Drawn for large headlines | Marketing headlines, hero text |
| Script | Mimics handwriting | Rare, decorative moments |

"Display" in a font's name does not make it a display font. Many families ship a `Display` cut for large sizes and a `Text` cut for small ones (SF Pro, for example). Use the cut matching the size you are setting.

## Fallback stacks for a type change

When a type change is asked for, two routes. `system-ui` gives each operating system's own interface face. A brand face, free or commercial, is a brand decision and still needs a fallback stack of widely installed faces with similar metrics.

```css
/* The platform's native interface face */
html {
  font-family: system-ui, sans-serif;
}

/* Brand face with safe fallbacks */
html {
  font-family: "Brand Sans", "Helvetica Neue", Arial, sans-serif;
}
```

## Formats

| Format | Notes |
| --- | --- |
| `.woff2` | Brotli compression, broadly supported. Use this on the web. |
| `.woff` | Older compression. Fallback only for very old browsers. |
| `.ttf` / `.otf` | Desktop formats with no built-in compression, so larger files. Only when there is no other option. |

## Loading

The project's loader comes first. Some framework loaders (for example `next/font`) already set `font-display` and generate a metric-matched fallback; check what the loader emits before adding anything by hand.

| `font-display` | Behavior | Use for |
| --- | --- | --- |
| `swap` | Fallback text at once, swapped when the face arrives | Body and interface text |
| `optional` | Uses the face only if it arrives almost immediately, otherwise keeps the fallback for that page view | Text where a late swap shifts layout more than the brand face is worth |
| `block` | Invisible text for up to about three seconds | Icon fonts only, where fallback glyphs would show ligature names |

A swap still shifts layout when the fallback's metrics differ. Close the gap with a fallback `@font-face` tuned by `size-adjust`, `ascent-override`, `descent-override` and `line-gap-override`, generated by the loader or a font-metrics tool rather than guessed:

```css
@font-face {
  font-family: "Brand Fallback";
  src: local("Arial");
  size-adjust: 107%;
  ascent-override: 90%;
}

body {
  font-family: "Brand", "Brand Fallback", sans-serif;
}
```

Preload only the one or two faces visible above the fold, as `woff2` with `crossorigin`.

## Anatomy of a typeface

| Term | Meaning |
| --- | --- |
| x-height | Height of a lowercase `x` |
| Cap height | Height of uppercase letters |
| Baseline | The invisible line letters sit on |
| Ascender | Part of a letter rising above the x-height |
| Descender | Part dropping below the baseline |

These measurements are why two fonts at the same `font-size` look like different sizes. A large x-height looks bigger.
